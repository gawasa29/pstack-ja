### 自動操縦スタック（Autopilot-stack）

Autopilot-full プレイブックを実行します。ただしマージはしません。

1. **ステップ 5 の代わりに、検証済みで止めます。** 各 PR が現在の head で検証済みかつグリーンになったら止め、PR をオペレーターに引き渡します。引き渡した後は、オペレーターの許可なしに誰も push しません。ループの tick プロンプトがすべてこのファイルを名指しするので、どの tick もマージ禁止のルールを目にします。
2. **PR をスタックするのは、他の PR の上に積む場合だけです。** これがステップ 3 の唯一の例外です。`playbooks/opening-a-pr.md` の**サイズとスタック**に従い、trunk ではなく相手 PR のブランチを base にします。ステップ 2 の trunk へのリベースの代わりに、各 PR は親 PR のブランチへリベースし、スタックの根だけが trunk へリベースします。下の PR に新しい head ができると、その上の PR は積み直しになり、積み直しで `git patch-id` が変わらなかった PR は判定を保ちます。

**返信内容：** マージされたものの代わりに、各 PR とその判定を並べます。
