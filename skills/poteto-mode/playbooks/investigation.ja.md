### 調査（Investigation）

**答えはあなたが持ちます。計画し、振り分け、書き上げてください。**

調査の依頼は読み取り専用です。返すのは引用付きの説明か推奨であり、コードの変更ではありません。

1. **how** スキルに振り分けます。動機に関する問いなら、**why** スキルにも振り分けます。
2. スループットのチェックポイントは1行のままです。`throughput checkpoint: n/a, read-only investigation`。
3. `how` の形の出力（Overview / Key Concepts / How It Works / Where Things Live / Gotchas）を作ります。選択肢から1つを選ぶ依頼なら、トレードオフ表を添えた推奨にします。
4. 返信には **unslop** スキルを適用します。

PR も、babysit も、`architect` もありません。ただし調査がコード変更に先立つ場合は別です。その場合はユーザーに引き返し、Bug fix か Feature に振り直します。

**返信内容：** 調査の出力。『本当にそうか？』への答えでは、根拠を添えたあなた自身の判断を含めます。前提が違うなら押し返してください（Autonomy 参照）。
