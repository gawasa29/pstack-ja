# Slack の会話

## 検索の仕方

Slack の MCP はツールがさまざまです。どの Slack MCP が利用できるかを確認し、まずそのツールのスキーマを調べてください。`mcp_auth` が必要な場合があります。認証に失敗したら、止めてギャップとして報告してください。

1. **投稿者で絞った検索。** PR の作成者による、PR のマージ日の前後のメッセージです。範囲が大きく絞られ、しばしば狙いの情報が当たります。
3. **PR の URL で検索。** Slack では PR がレビューや議論のときにリンクされることがよくあります。PR の URL（または `/pull/<number>` だけ）で検索してください。
4. **エラー文字列で検索。** コードが特定のエラーを扱っているなら、そのエラー文字列で検索してください。インシデントのスレッドが見つかることがよくあります。

## よくある落とし穴

- **チャンネルの発掘には限界があります。** 古いメッセージは保持ポリシーで消えていることがあります。ある日付より前が見つからない場合は、保持期限の崖を記録してください。
- **検索できない DM。** 多くの決定は検索できない DM の中で行われます。それは拾えません。既知の制約です。
- **冗談を「決定」と取り違える。** Slack はくだけた場です。「Lol just do the thing」は、その後にコミットが続いたとしても決定ではありません。検討された議論を探してください。
- **単発のメッセージでの文脈の崩壊。** スレッドがないと、1 つのメッセージは文脈の中とは違って読めます。必ずスレッドを取得してください。
- **認証の失敗。** MCP が認証されていないなら、止めてください。発見をでっち上げないこと。Slack が検索できなかったと報告してください。
